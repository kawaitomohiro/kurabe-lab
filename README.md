# くらべ方ラボ

小学5年算数「単位量あたりの大きさ」（速さまで）の練習アプリです。URLを開くだけで始まります。

**ひらく → https://kawaitomohiro.github.io/kurabe-lab/**

- 6つのタブ：しくみ／図をかく／式と答え／文章題／はやさ／うでだめし
- 文章から2本の数直線をかき、矢印の向き（なぜその向きか）と×÷を選び、式と答えまで進む
- まちがえたら問い返しとヒント。数字は画面のキーで入れる
- 1あたりを求める・全体を求める・いくつ分を求める、の3つを同じ図でくり返し練習
- 名前の入力・ログインはなし。記録はその端末のブラウザの中だけ（どこにも送らない）

1枚のHTML（`docs/index.html`）を GitHub Pages で配信しています。
